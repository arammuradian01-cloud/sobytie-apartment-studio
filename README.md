# СОбытие — P04 / E02 / V01

Сайт семейной квартиры с двумя вариантами расстановки. Семья: родители и две дочери, общая детская. P04 — планировка и документы; T04 — интерфейс по образцу TATE.

Основной адрес: https://sobytie.aram-sites.duckdns.org/
Зеркало: https://arammuradian01-cloud.github.io/sobytie-apartment-studio/

Обзор, срез стен, вид сверху, прогулка на уровне глаз, 44 интерактивных элемента B / 40 A, свет, полноэкранный режим с резервным разворачиванием сцены в окне браузера, крупные интерьерные виды и переход из них в ту же комнату. Два ракурса детской B. Мини-план и экранные кнопки движения. Каталог с редактируемыми локальными ценами и количествами.

E02: проектное окружение к сдаче корпуса 2 и сценарий полностью завершённого квартала; дата, время по Москве, сезонные пресеты и движение солнца с тенями. Вид из трёх жилых помещений. Генплан застройщика, привязка по панораме 2025 года и соседние здания OpenStreetMap. Ориентация оценочная ±10°, высоты условны; это наглядный сценарий, не расчёт нормативной инсоляции. Источники: `public/exterior/source.json`.

V01: 10 полноценных изображений отделки, мебели, текстиля и света, включая отдельный ракурс двух учебных мест в детской B. Созданы image_gen по ракурсам модели P04; это художественные AI-концепции, не фотографии готовой квартиры. Свет и вид за окном на этих изображениях не меняются бегунком. Описание: `public/interiors/source.json`.

Файлы проекта P04 доступны из интерфейса. Геометрия не обмерная; инженерные точки и мебель — эскиз. Нативные Blender A/B и SketchUp A/B находятся отдельно в `sobytie/models/`; новый экстерьер E02 работает на сайте и пока не перенесён в эти файлы.

Сборка: `npm ci && npm run build`. Публикуется только `dist/`; относительный base поддерживает корень домена и подкаталог GitHub Pages. Нативные модели и приватные исходные фотографии в сайт не входят.
