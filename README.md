# СОбытие · P04 / T03

Интерактивный эскиз квартиры: два варианта, прогулка, 44 элемента в B / 40 в A, подбор 40 позиций с источниками и редактируемым ориентиром стоимости.

https://arammuradian01-cloud.github.io/sobytie-apartment-studio/

B развивается для семьи с общей детской. Проход у нижнего стула около 123 см, после сдвига на 30 см — 93 см. Два личных шкафа по 120 см, ящики кроватей, увеличенный шкаф прихожей. Кухня: 50 + 5×600 + 500 мм.

Данные: `public/project/project.json` и `catalog.json`. Актуальные PDF/XLSX — в разделе файлов сайта. P02/P03 оставлены как история. Цены каталога и проектные резервы разделены; товары не заказаны.

Геометрия по официальной графике застройщика, не по обмеру. Материалы и серийные предметы в модели показаны условно. Камера имеет радиус 16 см. Монтажные схемы, инженерные расчёты и рабочая деталировка требуют отдельной разработки.

## Запуск

`npm ci` → `npm run dev` / `npm run build`. Vite base настроен для отдельного GitHub Pages репозитория. Сайт статический; изменения сметы хранятся в localStorage браузера.
