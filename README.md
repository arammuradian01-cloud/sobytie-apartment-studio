# СОбытие / квартира для семьи

Два варианта расстановки для семейной квартиры с общей детской. P02 — планировочный альбом; T01 — интерактивный эскизный прототип.

- **B:** нижняя комната — общая детская с двумя кроватями, двумя учебными местами и двумя равными шкафами; родители в верхней спальне.
- **A:** нижняя комната — спальня родителей с ванной; детская наверху, учебные места в гостиной.

## Возможности

Обзор, вид сверху, прогулка WASD/стрелками и сенсорными кнопками; переходы между шестью помещениями; мини-план с положением камеры; срез стен; свет; открывающиеся двери, фасады и ящики с сохранением состояния отдельно для каждого варианта. Галерея содержит виды той же модели. PDF, схемы SVG, GLB и ведомость мебели CSV доступны на сайте.

## Запуск

Node.js 22.12+:

```sh
npm ci
npm run dev
npm run build
```

GitHub Pages публикуется workflow `.github/workflows/pages.yml` после push в `main`. В настройках Pages источник — GitHub Actions. Vite использует относительный base, поэтому сайт работает в подпапке репозитория.

## Данные и точность

`public/project/project.json` содержит контуры, масштаб, дверные проёмы и мебель обоих вариантов. Схемы и модели построены по этим данным. Координаты JSON заданы в системе исходного SVG; масштаб и начало координат находятся в самом файле. GLB — метры, Y вверх; Blender-исходники в локальном проекте — метры, Z вверх.

Источник: [план застройщика](https://dom-sobytie.ru/upload/plans/30.06.02.070.svg). Масштаб восстановлен по трём подписанным площадям, около 28,222 мм на единицу SVG. Размеры не являются обмером. Подписи площадей двух спален в сохранённом фото и текущем SVG расходятся; обозначения «верхняя» и «нижняя» относятся к контурам. Высота 3,10 м и конструкция окон условны. Мебель имеет проектные внешние габариты.

Навигация использует радиус камеры 16 см, контуры пола, мебель и подвижные створки. Это помощь при сравнении, а не проверка нормативной доступности. Рабочая документация и подбор изделий выполняются после обмера. Бытовые компромиссы и исходные ограничения раскрыты в PDF.

Исходные семейные файлы и референсы не включены в этот репозиторий. Текстура паркета: [Poly Haven / herringbone parquet](https://polyhaven.com/a/herringbone_parquet), [CC0](https://polyhaven.com/license). Оригинальные проектные схемы и модели подготовлены для этого прототипа.
